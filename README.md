# biom5350-seq-tools
\#biom535-seq-tools

Sequence utilities for BIOM5350 including a script that computes GC content for sequences in a FASTA file.

\#\#Usage

python gc_content.py example.fasta

\#\#Output

Prints name, length, GC content and AT content for each sequence, with mean GC content across all sequences
